How to use Sennelier Studio

Your data is private. Everything is saved only in this browser, on this device. Nothing is sent anywhere.

🎨 Collection

Tap a colour to mark it as owned (a ✓ appears). Tap the ☆ on a colour to add it to your wishlist. Use the search box and the filter to find colours. Switch between ranges (Oil Pastels, Soft Pastels…) using the buttons at the top of the Collection tab.

📓 Notes

Write anything — wishlist ideas, techniques, colour-mixing notes. Edit or delete notes whenever you like.

🖼️ Art Journal

Click ＋ Add art to add a photo of a piece, plus a title, a date and an optional note. Your photos are stored in this browser.

💾 Backups

Click ⬇ Export backup to download a file that saves everything (collection, notes and photos). Keep that file safe. On a new computer or browser, click ⬆ Import backup and choose that file to restore it all.

⚠️ Clearing this site's data — or switching to a different device or browser — removes everything. So export a backup now and then, just like saving a file.

🤖 Growing this app with ChatGPT

This app is just a few files: index.html, styles.css, app.js, and data/collections.js. To add a new pastel range, add an entry to data/collections.js. The README explains the full structure.
